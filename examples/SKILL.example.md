# Aesthetic Profile — Acme — warm editorial

This taste profile favors sharp, square corners. Lean into the spirit of: Sharp · Expressive, Packed · Warm, Warm · Sharp, Light · Packed. Steer away from: Uniform · Dark, Dark · Minimal, Airy · Cool, Packed · Minimal.

## Design principles

- **Type contrast → Dramatic** (+17): high typographic contrast with large display type — **key driver**.
- **Corners → Sharp** (-24): sharp, square corners — **key driver**.
- **Geometry → Geometric** (-14): geometric, hard-edged shapes — **key driver**.
- **Saturation → Muted** (-6): a muted, desaturated palette. _(exploratory)_
- **Tone → Dark** (+1): a dark, low-light canvas. _(exploratory)_
- **Temperature → Warm** (+8): warm color temperature. _(exploratory)_
- **Finish → Refined** (-5): a polished, refined finish. _(exploratory)_
