# Aesthetic Profile — Acme — warm editorial

This taste profile favors a light, bright canvas and sentence-case text. Lean into the spirit of: Light · Packed, Corporate Clean, Light · Expressive, Packed · Muted. Steer away from: Dark · Muted, Dark · Packed, Light · Minimal, Airy · Cool.

- **Type voice → Expressive** (+12): expressive, characterful display/serif type — **key driver**.
